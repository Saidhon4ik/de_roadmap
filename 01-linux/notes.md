# Linux Cheat Sheet — Stage 1 (Final)

## Навигация
```bash
pwd                 # где я сейчас (абсолютный путь)
ls                   # список файлов
ls -la               # + скрытые файлы + права/владелец/размер
cd path              # перейти в папку
cd ..                # на уровень выше
cd ~                 # домой
cd -                 # вернуться в предыдущую папку
```

## Пути
```
/home/user/project   # абсолютный — от корня /, работает откуда угодно
./project            # относительный — от текущей папки (pwd)
../project           # относительный — на уровень выше от текущей позиции
../../project        # на два уровня выше
```
Смысл относительного пути всегда зависит от того, где ты сейчас (`pwd`). Абсолютный — никогда не меняется, независимо от текущей локации.

## Файлы и папки
```bash
mkdir name           # создать папку
mkdir -p a/b/c        # создать вложенные папки сразу, без ошибки если уже есть
touch file.txt        # создать пустой файл (или обновить timestamp существующего)
rm file.txt            # удалить файл
rm -r folder/           # удалить папку рекурсивно
rm -rf folder/           # рекурсивно + без подтверждения (ОСТОРОЖНО, без корзины, без возврата)
cp src dst                # копировать файл
cp -r src_dir dst_dir       # копировать папку рекурсивно
mv src dst                  # переместить / переименовать
```

## Чтение файлов
```bash
cat file.txt           # весь файл целиком в stdout
less file.txt           # постранично, навигация стрелками, q — выйти, / — поиск внутри
head file.txt             # первые 10 строк по умолчанию
head -n 20 file.txt        # первые 20 строк
tail file.txt               # последние 10 строк по умолчанию
tail -n 50 file.txt           # последние 50 строк
tail -f file.txt               # живой хвост — обновляется в реальном времени (логи в проде)
```

## Права доступа (chmod) — численная логика

Права = 3 группы (владелец / группа / остальные), каждая = 3 бита (read/write/execute).

| Бит | Значение | Цифра |
|-----|----------|-------|
| r (read) | можно читать | 4 |
| w (write) | можно изменять | 2 |
| x (execute) | можно запускать (файл) / заходить внутрь (папка) | 1 |

Цифра для группы = сумма битов. Примеры:
```
7 = rwx  (4+2+1 — всё)
6 = rw-  (4+2 — читать+писать, без execute)
5 = r-x  (4+1 — читать+заходить, без write)
4 = r--  (4 — только читать)
0 = ---  (ничего)
```

Полная команда = три цифры подряд: владелец / группа / остальные.

```bash
chmod 644 file.txt     # rw-r--r--  владелец rw, остальные read-only — стандарт для ФАЙЛОВ
chmod 755 folder/        # rwxr-xr-x  владелец полный доступ, остальные читают+заходят — стандарт для ПАПОК
chmod 600 secret.json      # rw-------  только владелец — для credentials/ключей/токенов
chmod 700 private_folder/    # rwx------  только владелец видит и заходит
chmod +x script.sh             # добавить execute (альтернативный синтаксис, без чисел)
```

**Важно:** для папок `x` = разрешение заходить внутрь (`cd`), НЕ "запуск программы". Без `x` не зайдёшь даже будучи владельцем, даже если есть `r` (увидишь список файлов через `ls`, но не зайдёшь внутрь).

## Процессы
```bash
ps aux                  # все процессы всех пользователей (без aux — только твои в текущей сессии)
ps aux | grep python      # отфильтровать процессы по имени
kill <PID>                  # завершить процесс по ID (мягко, SIGTERM)
kill -9 <PID>                 # принудительно (SIGKILL, если не отвечает на обычный kill)
htop                            # живой интерактивный монитор CPU/RAM по процессам (q — выйти)
```

## Диск
```bash
df -h                  # свободно/занято места на диске (по разделам), -h = human-readable (GB/MB)
du -sh folder/            # сколько весит конкретная папка (-s = summary, -h = human-readable)
du -sh */ | sort -h         # размер каждой папки в текущей директории, отсортировано по возрастанию
```

## Pipes и redirects
```bash
command > file.txt       # записать output в файл (ПЕРЕЗАПИСЬ существующего содержимого)
command >> file.txt        # дозаписать в конец файла (не перезаписывает)
cmd1 | cmd2                  # output cmd1 становится input cmd2

# Примеры:
find . -name "*.md" | wc -l            # найти .md файлы → посчитать сколько штук
ps aux | grep python                      # все процессы → отфильтровать только python
tail -n 50 error.log | grep ERROR           # последние 50 строк лога → найти строки с ERROR
```

## Поиск — find и grep

```bash
find . -name "*.md"              # найти файлы с расширением .md, начиная от текущей папки (.)
find / -name "config.json"          # искать от корня системы (медленнее, шире охват)
find . -type f -name "*.py"           # -type f = только файлы (не папки)
find . -type d -name "logs"             # -type d = только папки
find . -mtime -1                          # файлы изменённые за последние 1 день
find . -size +100M                          # файлы больше 100MB

grep "error" file.txt                # найти строки содержащие "error" в файле
grep -i "error" file.txt               # -i = без учёта регистра (Error, ERROR, error — всё найдёт)
grep -r "TODO" .                         # -r = рекурсивный поиск по всем файлам в папке
grep -n "error" file.txt                   # -n = показать номер строки где нашлось
```

## Частые ошибки (из собственной практики)
- `cd` в папку, которой ещё нет → сначала `mkdir`, потом `cd`
- `chmod 644` на папку → не зайдёшь внутрь, даже будучи владельцем (нужен `x` → используй `755`)
- `rm -rf` без проверки `pwd` → может удалить не то, без возврата
- credentials-файлы (`*.json` ключи, токены) с открытыми правами (`644` и слабее) → всегда `chmod 600`
- путать `du` (вес папки) и `df` (место на диске) и `htop` (CPU/RAM процессов) — три разных инструмента под разные вопросы

## ❓ Comprehension Check (с ответами)

**1. Чем отличается абсолютный путь от относительного?**
Абсолютный начинается от корня `/`, работает одинаково откуда угодно. Относительный отсчитывается от текущей позиции (`pwd`), поэтому его смысл меняется в зависимости от того, где ты сейчас находишься.

**2. Зачем нужен pipe `|`?**
Передаёт output одной команды как input следующей, без промежуточных файлов. Пример: `find . -name "*.md" | wc -l` — найти файлы и сразу посчитать их количество.

**3. Как посмотреть последние 50 строк большого лога без открытия всего файла?**
`tail -n 50 file.log` — читает только конец файла, не грузит весь файл в память.

## 🎤 Mini Interview Q&A

**Easy: "Как посмотреть какие процессы запущены?"**
`ps aux` — показывает все процессы всех пользователей с PID, CPU%, MEM%. Для живого мониторинга — `htop`.

**Medium: "Что делает `chmod 755`?"**
Устанавливает права: владелец — rwx (полный доступ), группа и остальные — r-x (читать + заходить, без записи). Стандартная схема для папок и исполняемых скриптов.

**Hard: "Сервер не отвечает, диск забит — как найдёшь что жрёт место?"**
Сначала `df -h` — подтвердить какой раздел забит. Потом `du -sh */ | sort -h` в подозрительной директории (например `/var/log` или `/home`) — отсортированный по размеру список папок, сразу видно виновника. `htop` тут не поможет — это для CPU/RAM, не для диска.
